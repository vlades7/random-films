# 🎰 Кино-Джекпот

Игровой автомат для выбора фильма на вечер. Vue 3 + Vite + TypeScript. Работает целиком в браузере: сервер и база данных не нужны.

## Запуск

```bash
npm install
npm run dev
```

Браузер откроется сам.

## Сборка и публикация

```bash
npm run build
```

В папке `dist/` получится обычный статический сайт: `index.html` и папка `assets/`. Его можно выложить на любой статический хостинг (GitHub Pages, Netlify, Yandex Object Storage и т.п.). Пути в сборке относительные, поэтому сайт работает и из подпапки.

**GitHub Pages:** при пуше в ветку `main` workflow [.github/workflows/deploy-pages.yml](.github/workflows/deploy-pages.yml) сам собирает сайт и кладёт его в ветку `gh-pages`. Сайт доступен по адресу https://vlades7.github.io/random-films/.

Открыть `dist/index.html` двойным кликом не получится: браузеры не запускают такие скрипты с `file://`. Локально сборку можно посмотреть командой `npm run preview`.

## Где лежат данные

Всё хранится в браузере, в IndexedDB. У каждого человека и в каждом браузере свои данные.

| Хранилище | Что внутри |
| --- | --- |
| `data` → `lists` | списки фильмов (`name`, `enabled`, `color`, `films[]` с `title`, `image`, `watched`) |
| `data` → `history` | история выпадений: `title`, `image`, `date` (`ДД.ММ.ГГГГ, ЧЧ:ММ:СС`), `listName` |
| `images` | картинки, загруженные с компьютера (в данных фильма записаны как `idb:<id>`) |

Постеры, найденные в интернете, хранятся как ссылки.

При первом запуске показываются демо-списки ([src/seed.ts](src/seed.ts)).

**Резервная копия:** кнопки «💾 Сохранить копию» и «📂 Загрузить копию» внизу страницы. Копия — один JSON-файл, загруженные картинки встроены в него. Через неё же данные переносятся на другое устройство. Загрузка копии заменяет текущие данные.

Если очистить данные сайта в браузере, списки пропадут. Поэтому лучше иногда сохранять копию.

## Управление

- Потяните рычаг мышкой вниз, кликните по нему, нажмите «КРУТИТЬ!» или Пробел/Enter.
- Переключатели «Играют:» над автоматом включают и выключают списки для розыгрыша.
- Постер фильма можно добавить в редакторе фильма: клик по постеру, перетаскивание файла, Ctrl+V или URL.
- 📋 Импорт: вставьте текстовый список по фильму на строку. Нумерация вида `1.` и маркеры `-` убираются, дубли пропускаются.
- Фильм можно перетащить мышью в другой список.

## Просмотренные фильмы

- Выпавший фильм отмечается как просмотренный (`watched: true`) и больше не участвует в розыгрыше. В списке у него чёрно-белый постер со штампом «ПРОСМОТРЕНО», и он перемещается в конец.
- Отметку можно переключить кнопкой ✓/↺ на постере (видна при наведении) или галочкой в редакторе фильма.
- Когда непросмотренных фильмов во включённых списках не остаётся, приложение показывает уведомление, табло пишет «Всё просмотрено», а рычаг блокируется.
- «Сбросить историю» отметки не снимает.

## Автоподбор постеров

Браузер сам ищет постеры в Википедии: сначала в русской, затем в английской, а запрос латиницей сразу идёт в английскую ([src/posterSearch.ts](src/posterSearch.ts)).

- Поиск запускается сам после добавления фильма без картинки и после импорта. Для фильмов без картинки есть кнопка «🖼 Постеры» в списке.
- Если название однозначно совпало с одной статьёй, постер ставится автоматически. Год в названии, например `Перелом (2007)`, учитывается.
- Если вариантов несколько, открывается окно выбора. В нём можно уточнить запрос, пропустить фильм или пропустить все.
- В редакторе фильма кнопка «🔍 Найти в интернете» показывает варианты вручную.
